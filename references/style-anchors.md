# 风格参考坐标：把"我要那种感觉"翻译成可执行参数

> 用户说"高级感""治愈""很燃""有质感"时，这些词**不能写进提示词**（它们落不到画面上）。
> 但用户说的确实是有效的创作意图。这份文件做的事是：**意图 → 视觉特征 → 具体参数**。

---

## 一、为什么需要中间这一层

```
用户的语言          本文件的活              分镜表的语言
"要那种高级感"  →  调性 → 视觉特征 → 参数  →  85mm f/1.8 / 侧逆光 / 单色分区 / 静默
```

跳过去直接写"高级感"的后果：
- 模型把它当形容词，忽略或随机化
- 不同的镜头对"高级感"理解不一致，成片调性散掉
- 出了好片也不知道好在哪，无法复现

**中间这一层就是把模糊意图固化成可复用、可复现的参数组合。**

---

## 二、五轴映射法（把任何调性拆成 5 轴）

任何一个调性词，都能拆成下面 5 轴上的具体取值。**拆不出 5 轴 = 这个词太虚，先跟用户确认他要的到底是什么。**

| 轴 | 取值范围 | 常见错误 |
|---|---|---|
| **① 构图与景别** | 主体占画面比、留白比例、信息密度、视线朝向 | 只写"好看的构图" |
| **② 运镜与节奏** | 固定 / 缓推 / 环绕 / 手持；平均镜长；切点位置 | 一镜写多个运镜 |
| **③ 光线** | 方向（顺/侧/侧逆/顶/底）、硬度、光比、时段 | 只写"光线很美" |
| **④ 色彩与材质** | 主色调关系、饱和度、胶片模拟、材质质感 | 只写"色调高级" |
| **⑤ 声音** | 主体音效 / 环境音 / 静默节点 / 有无配乐 | 只写"配点音乐" |

> 与 `lens-grammar.md` 的七维的区别：**七维是"每个镜头必须填什么"，五轴是"调性怎么决定那七维填什么"。**
> 七维是填空题，五轴是判分标准。

---

## 三、调性反查表（用户口头语 → 坐标）

用户说的话往往不是他真正要的。**先翻译意图，再落参数。**

| 用户说 | 真正要的是 | ①构图 | ②运镜节奏 | ③光线 | ④色彩材质 | ⑤声音 |
|---|---|---|---|---|---|---|
| **"高级感"** | 克制、稀缺、不解释 | 大留白（≥50% 空），主体占比小 | 固定或极缓推；镜长 ≥3s | 硬朗侧逆光勾边，光比大 | 低饱和单色系，1 种主材质 | 静默为主，几乎无配乐 |
| **"有质感"** | 材质可触摸 | 特写 / 大特写，主体占满 | 固定 | 侧逆光，光比 1:4 以上 | 胶片模拟（Eterna / 250D），高细节 | 材质拟音（布料/金属/纸张） |
| **"干净"** | 信息少、秩序感 | 大留白 + 少元素，对称或三分 | 固定 | 均匀柔光，光比 ≈1:1 | 白 / 浅灰 / 单色，高调 | 单一环境音，无配乐 |
| **"治愈"** | 安全、暖、慢 | 中景为主，人物居中 | 缓推 / 固定；镜长 4–6s | 暖侧光 3200–4000K，柔 | 暖白调，低对比，低饱和 | 自然环境音 + 静默，轻柔配乐可 |
| **"很燃"** | 冲击、加速 | 中近景 + 低角度仰拍，主体大 | 快切；单镜 1–2s；甩镜点缀 | 硬光高对比，逆光剪影 | 高饱和 / 青橙对比 | 强音效 + 冲击前静默 + 鼓点 |
| **"大片感"** | 体量、纵深 | 大远景开场 → 人物远景（比重悬殊） | 缓推 / 升降 / 环绕 | 黄金时刻或冷调大光比 | 电影胶片模拟，青橙或冷暖分区 | 低频环境音 + 空间回响 |
| **"文艺"** | 疏离、留白、不解释 | 大留白，人物偏置，背对镜头 | 固定 / 极缓；镜长 ≥5s | 自然光，柔和侧光 | 低饱和，冷灰绿 | 环境音为主，无配乐 |
| **"真实"** | 不摆拍 | 中远景为主，构图不完美 | 手持轻微晃动 / 跟拍 | 自然光，不打光 | 无明显调色，颗粒 | 现场收音，保留杂音 |
| **"未来科技"** | 秩序、体量、精准 | 大留白 + 强对称，几何线条 | 环绕 / 升降；剪辑对鼓点 | 冷光 + 单点亮色源 | 深蓝冷底 + 单点亮色 | 电子音效 + 低频 |
| **"国潮"** | 东方审美进现代场景 | 材质微距 + 器物居中 | 慢节奏，缓推 | 自然光，柔和 | 红金 / 青瓷，低饱和 | 传统乐器点缀 + 环境音 |

**要避开的（反向坐标）**：

| 想避免的感觉 | 通常是这几项做错了 |
|---|---|
| 廉价 / 广告感重 | 高饱和 + 元素堆叠 + 影棚平光 + 满屏配乐 |
| 假 / 摆拍感 | 完美对称 + 影棚打光 + 过精致的动作 |
| 土 | "很燃"的节奏配了高饱和堆叠元素（燃的元素对了，色彩错了） |
| 空 / 记不住 | 全片平均用力，没有唯一视觉高潮 |
| 拖沓 | 镜长过平均值 + 在动作完成后才切 |

## 四、落地三步

1. **认调性**：从用户的话里认出**一个**（不是一个）核心调性词——"又高级又燃"不存在，让用户选一个
2. **查坐标**：查第三节拿到 5 轴的初步取值
3. **落到分镜表**：把 5 轴取值填进七维，逐镜保持一致；**同一支片子里 5 轴取值不能中途变**

> 判据：如果分镜表第 5 镜的光线/色彩跟第 1 镜取值不同，调性就断了——这就是"调性散掉"的技术定义。

---

## 五、两条铁律

- **调性词不进提示词正文。** "高级感""治愈""很燃"只用来查表，写进 prompt 的是查出来的参数。
- **调性决定的是"取舍"，不是"加法"。** 比如"高级感"的核心是**限制**（一种材质、一个高潮、大留白），不是加更多元素。**加元素永远拍不出高级感。**

---

## 六、情绪调性坐标（故事片专用）

故事片的"调性"不是风格，是**情绪**。同一个人设、同一个场景，情绪不同，5 轴取值完全不同。

| 情绪调性 | ①构图与景别 | ②运镜与节奏 | ③光线 | ④色彩材质 | ⑤声音 |
|---|---|---|---|---|---|
| **孤独** | 大留白，人物极小且偏置/背对 | 固定长镜（≥5s），不切 | 自然柔光，人物半明半暗 | 冷灰蓝，低饱和 | 空旷环境音，**无配乐**，静默多 |
| **温暖** | 中景为主，人物居中 | 缓推；切点给反应 | 暖侧光 3200–4000K，柔 | 暖白调，低对比 | 自然环境音 + 静默 |
| **压抑** | 构图受限——门框/窗框/前景遮挡挤压主体 | 固定，镜长短于常规（2–3s） | 顶光或底光，光比大 | 低饱和冷绿，脏灰 | **低频嗡鸣**，环境音闷，无配乐 |
| **释然** | 留白打开，人物回到画面中部 | 镜长变长（≥5s），缓拉 | 光线回暖（**与压抑段形成色温差**） | 饱和度回升，暖调 | 环境音**第一次出现**，仍无配乐 |
| **荒诞** | 绝对对称、正面固定机位 | 完全静止，不切或极慢切 | 平光，光比 1:1，无戏剧性 | **正常饱和度**（越正常越荒诞） | 日常环境音，配乐刻意错位 |
| **怀旧** | 中景，柔焦感 | 缓推 | 暖黄柔光，轻微过曝 | 暖黄 + 颗粒 | 老物件拟音（胶片走片声 / 收音机底噪） |

### 用法

1. 先定这场戏的情绪（一个，不要两个）
2. 查表拿 5 轴取值，填进分镜表
3. **逐镜核对 5 轴是否一致**——第 5 镜的光线突然变了，情绪就断了
4. 转场处要"变情绪"时，**至少改 3 个轴**，只改一个轴观众感觉不到

### 与情绪曲线的配合

`production.md` 六.6.2 要求把情绪曲线逐镜标值（1–5）。这里补上**参数映射**：

| 情绪值 | 参数表现 |
|---|---|
| 1（最低） | 最大留白、最冷色调、最长镜、最空的声音 |
| 3（中） | 中等景别、自然色、正常镜长 |
| 5（最高） | 特写、光比最大、镜长最短、声音最满（或**最静**） |

> 情绪高点用"最静"还是"最满"？**看类型**：释放型情绪（哭、笑、和解）用"静"；爆发型情绪（愤怒、决裂）用"满"。用错会出现"情绪到了但没感觉"。
