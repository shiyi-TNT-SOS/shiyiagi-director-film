# 分镜 → 视频模型提示词（故事片场景转换规则）

## 七段顺序（句首权重最高，顺序不能乱）

```
[主体动作] + [景别角度] + [单个运镜] + [光线] + [色彩] + [画幅+时长] + [声音]
```

| 段 | 内容 | 示例 |
|----|------|------|
| 主体动作 | 谁、做什么、情绪怎么通过动作流露 | 她低头把信折好塞进口袋，肩膀微沉 |
| 景别角度 | 景别+角度（角度承载权力/视角） | 近景，微俯 |
| 单个运镜 | 只写一个核心运镜 | 缓推 / 固定 / 缓拉 |
| 光线 | 方向+硬度+色温（光影讲心理） | 窗边侧光，冷调 |
| 色彩 | 主色+点缀（色彩讲基调） | 青灰底+暖灯点 |
| 画幅+时长 | 固定 2.39:1 + 秒数 | 2.39:1 电影画幅 / 5秒 |
| 声音 | 台词或音效/环境音 | 远处的钟声+静默 |

> 主体动作永远句首。把"电影感""8K""超高清"放句首 = 把预算花在没用的词上。

## 故事片硬约束（必查）

- [ ] 生成单元 4–10 秒（成片镜头 1–2 秒，余量给剪辑），可多镜（Shot 1/2/3）拼接成一场。详见 `references/emotion-shot-design.md` 第六节。
- [ ] 画幅标注 2.39:1，主体占画面 ≥60%。
- [ ] 排除文字用构图（"画面留白处无标识"），**不写"无字幕/无文字"**（会反被召唤出文字）。
- [ ] 台词短、有潜台词；无台词只给音效与环境音，无背景配乐。
- [ ] 情绪靠镜头（景别/光影/色彩/调度）表达，不靠旁白形容词。
- [ ] 面部微表情交给肢体与调度，特写少给、给就给正脸。

## 引擎参数差异

**完整能力矩阵、选引擎决策树、负面词的两种写法，统一见 `production.md` 第四章「引擎能力矩阵」**（含 2026-10 快照）。引擎事实只维护那一处，避免四处漂移。

故事片额外需要记住的：

- **2.39:1 是硬要求**：这是本 skill 的质感基础，但也是竖屏适配的最大冲突点——三种适配方案见 `platform-specs.md` 第三章。
- **干净正脸 + 短台词**利于原生音频对口型；情绪靠表演而非台词，所以无台词镜只给环境音（见 base 五）。
- **一条 prompt 多镜**（Shot 1/2/3）可用于同场戏的镜头组，人物与光线更容易保持连续；但情绪高点建议单独一镜抽。
- **首尾帧接力别超过 4–5 跳**，每 3 跳用角色参考图回锁一次（见 `production.md` 一.1.4）。
- **需要精确落首尾帧**（如某个动作/情绪必须停在指定帧）优先可灵。

## 反例（不要这样写）

- ❌ "电影感史诗级震撼的孤独故事，8K超高清无字幕" — 全是废词 + 触发文字召唤 + 句首浪费。
- ❌ 一镜写"先推再摇再拉" — 运镜打架，模型糊。
- ❌ "人物很悲伤" — 形容词不产画面；应写"低头、肩沉、视线落地、环境压暗"。

## 正例（这样写）

"她低头把信折好塞进口袋肩膀微沉，近景微俯，固定机位，窗边侧光冷调，青灰底暖灯点，2.39:1电影画幅/5秒，远处钟声与静默"
