# 情绪镜头语法速查（故事片 6 维）

> 故事片靠"情绪"驱动，镜头语法要把抽象情绪落成具体参数。六维：景别 / 角度 / 运镜 / 光影 / 色彩 / 构图。
> 普通导演四层结构见 `shiyiagi-director-ad-tvc` 的 lens-grammar；本文件只讲故事片的情绪映射。

## 1. 景别 = 情绪距离

| 景别 | 情绪含义 | 用法 |
|------|----------|------|
| 大远景 EWS | 疏离、渺小、命运感 | 人物被环境吞没、孤独 |
| 全景 WS | 处境、关系 | 建置处境 |
| 中景 MS | 日常、平视 | 叙事主景别 |
| 近景 MCU | 情绪进入 | 内心波动 |
| 特写 CU | 情绪峰值、隐秘 | 关键反应、物件隐喻 |

> 越近越私密；情绪高潮给特写，但**特写给正脸**，不给侧脸乱抿嘴（AI 嘴部最弱）。

## 2. 角度 = 权力与视角

- **平视**：平等、纪实、代入。
- **俯拍**：弱势、被压制、疏离、宿命。
- **仰拍（15–25°）**：英雄、希望、压迫感。
- **荷兰角**：失衡、不安、心理异变（慎用，易廉价）。

## 3. 运镜 = 心理节奏

| 运镜 | 心理节奏 | 用法 |
|------|----------|------|
| 固定 | 凝视、克制、真实 | 情绪峰值、静默 |
| 缓推 | 逼近、聚焦内心 | 揭示 |
| 缓拉 | 抽离、释然、孤独 | 释放、收尾 |
| 缓移 | 陪伴、观察 | 建置、跟随 |
| 环绕 | 执念、审视 | 转折、凝视 |

> 故事片运镜要"慢而有目的"，避免剧烈手持/甩镜（那是动作片语言）。

## 4. 光影 = 心理

- **侧光/侧逆光**：体积、孤独、质感，故事片主力。
- **顶光**：压迫、审讯、孤立。
- **柔光平光**：温暖、安全、记忆。
- **硬光阴影**：内心撕裂、冲突。
- 避免通片平光大白——没有光影=没有心理。

## 5. 色彩 = 情绪基调

- **冷调（青蓝灰）**：孤独、压抑、疏离、理性。
- **暖调（橙黄）**：温暖、记忆、希望、家。
- **冷暖对撞**：人物内心冲突、时空交错（回忆用暖、现实用冷）。
- **去饱和**：悲悯、克制、纪实。
- 不靠"加滤镜"形容词，靠明确主色+点缀。

## 6. 构图 = 关系

- **留白**：孤独、等待、未完成。
- **框架构图（门窗框人）**：禁锢、旁观。
- **失衡构图**：不安、心理异变。
- **对称构图**：秩序、仪式、宿命。
- **前景遮挡**：窥视、隐秘、距离。

## 一句话铁律

**情绪不靠形容词，靠景别距离 + 光影心理 + 色彩基调 + 构图关系。** 镜头语法只是把这条落到画面上。
