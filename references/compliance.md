# 叙事内容合规红线

> 故事片常涉及真实事件改编、人物刻画、情感尺度，平台审核与法律风险高于纯视听广告。发布前务必过平台后台检测。以下为 2026-10 时点主要规则，过时以最新规范为准。

## 1. 真实事件与人物

- 改编真实事件：避免实质性歪曲导致误导；涉及公共事件以官方通报为准。
- 影射真实人物：不得构成诽谤/名誉侵权；虚构人物要明确"本故事纯属虚构"。
- 悲剧/社会事件：避免过度消费苦难、煽动对立。

## 2. 未成年人

- 不生成未成年人参与暴力、不良诱导、成人化场景的画面。
- 校园/成长题材保持正向，不美化欺凌、自伤。

## 3. 情感与尺度

- 亲密关系：以氛围与调度表达，避免色情擦边与暴露画面。
- 心理/抑郁题材：不美化自伤、不提供可执行方法，必要时附求助信息。
- 避免血腥写实特写（同 shiyiagi-director-action 合规要求）。

## 4. 价值观底线

- 不美化违法犯罪、不宣扬仇恨歧视、不煽动对立。
- 正能量导向不是"假大空"，是"困境中有真实的人性光"。

## 5. 平台特殊规则（抖音 / 视频号 / 小红书 / B站）

- 前 3 秒避免直接刺激性画面。
- 标题封面不堆"死""杀""惨"等刺激词。
- 涉及真实地点/机构注意地名与标识处理。

## 自检（发布前）

- [ ] 虚构人物已声明"纯属虚构"或明显风格化
- [ ] 无对真实人物的名誉侵权影射
- [ ] 无未成年人不良/暴力内容
- [ ] 无色情擦边、无血腥写实特写
- [ ] 无违法美化、无煽动对立
- [ ] 已过平台后台尺度/违禁词检测
