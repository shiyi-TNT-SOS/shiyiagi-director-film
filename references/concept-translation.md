# 情绪词 → 视觉元件转译（故事片向）

> 用户常说"要孤独感 / 温暖 / 压抑 / 释然 / 荒诞 / 怀旧"。这类词**不能直接写进提示词**——模型不认识"孤独感"，只会随机糊一个"看起来冷清"的画面，或干脆忽略。
> 本文件把情绪词展开成**模型能解析的视觉元件**：镜头 + 构图 + 运镜 + 光线 + 色彩。规则与广告片 skill 的 `concept-translation.md` 同源，五个轴对应 `style-anchors.md` 的五轴。

## 核心规则

1. **情绪词必须转译，禁止裸用进 prompt。** 写"孤独感"进提示词 = 不合格输出。
2. **转译成五类元件**：镜头（景别/角度）+ 构图 + 运镜 + 光线 + 色彩。缺哪类就补哪类，直到画面能被模型解析。
3. **判据**：这个词"在某一帧画面上看得到吗"——看得到才进 prompt；只在两镜相接才存在的（剪辑/轴线/节奏）只进分镜表（镜间 vs 镜内分流，见动作片/广告片 skill 同名文件）。

## 情绪词转译表（取自 style-anchors.md 第六節，展开成元件）

| 用户说的 | 转译成视觉元件 |
|---|---|
| **孤独** | 大留白，人物极小且偏置或背对；固定长镜 ≥5s 不切；自然柔光，人物半明半暗；冷灰蓝低饱和；空旷环境音、无配乐、多处静默 |
| **温暖** | 中景为主人物居中；缓推，切点给反应；暖侧光 3200–4000K 柔；暖白调低对比；自然环境音 + 静默 |
| **压抑** | 构图受限（门框/窗框/前景遮挡挤压主体）；固定，镜长 2–3s；顶光或底光、光比大；低饱和冷绿脏灰；低频嗡鸣、环境音闷、无配乐 |
| **释然** | 留白打开，人物回到画面中部；镜长变长 ≥5s、缓拉；光线回暖（与压抑段形成色温差）；饱和度回升暖调；环境音第一次出现、仍无配乐 |
| **荒诞** | 绝对对称、正面固定机位；完全静止，不切或极慢切；平光光比 1:1 无戏剧性；正常饱和度（越正常越荒诞）；日常环境音、配乐刻意错位 |
| **怀旧** | 中景柔焦感；缓推；暖黄柔光轻微过曝；暖黄 + 颗粒；老物件拟音（胶片走片声/收音机底噪） |

> 转译后用的是**参数**，不是词本身。例："孤独"→"大留白、人物背对、固定长镜、冷灰蓝、空旷环境音无配乐"，而不是"孤独感氛围"。

## 禁词三类（写进 prompt 一律不合格）

| 类 | 例子 | 为什么禁 |
|---|---|---|
| **① 空泛无落点** | 史诗、震撼、极致、沉浸式、视觉盛宴、文艺感（裸用）、有质感、高级感 | 连"转译表"都无可落地的元件，纯占预算 |
| **② 镜间概念** | 快速剪辑、匹配剪辑、保持轴线、节奏调整、运镜流畅 | 属剪辑/调度，只进分镜表，单镜 prompt 写无效 |
| **③ 抽象结果** | 很孤独、很治愈、很震撼、画面很美、情绪饱满 | 是评价不是画面，模型无法据此生成 |

> "孤独"本身不是禁词——它是**触发词**，必须立刻按上表转译成五类元件，转完把"孤独"二字丢掉。

## 否定词铁律（negation summons）

- 排除文字 / 字幕一律用**构图式排除**（"画面留白处无标识""字幕由后期叠加"），**绝不写 `no text / 无字幕`**——否定句会反被召唤出文字。
- 实物类排除（水印 / 慢动作 / 手指畸变 / 塑料感皮肤）可正常写。
- 字幕 / 品牌文字**始终由后期叠加**，不在 prompt 里要求生成文字。

- [ ] 用户给的情绪词已全部转译成五类元件，无裸词进 prompt
- [ ] 未使用禁词三类（空泛 / 镜间概念 / 抽象结果）
- [ ] 排除文字走构图，无 `no text / 无字幕`
- [ ] 字幕 / 品牌文字标注"后期叠加"，未要求生成文字
