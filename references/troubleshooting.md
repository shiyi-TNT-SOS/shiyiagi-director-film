# 生成失败排错表（症状 → 原因 → 改法）

> 生成不是一次过的。分镜对、提示词对，模型照样给你废片——本文件解决的就是这一步。
> 用法：先定位症状 → 按「常见原因」逐条排除 → 按「改法」动手。**改完只重试那一镜，不要重跑全片。**

---

## 零、先读这三条（能省掉一半返工）

1. **一次只改一个变量。** 同时改景别、光线、运镜，你判断不出是哪个起了作用，下一条还会踩同一个坑。
2. **先换生成方式，再改提示词。** 多数崩坏是「纯文生视频」本身的天花板。改图生视频 / 首尾帧接力 / 喂参考图，比在提示词上磨十遍有效。
3. **同一镜重试不超过 3 次。** 3 次还不行，说明是镜头设计不合理（比如让模型拍多人缠斗），回去改分镜，别在提示词里死磕。

---

## 一、人物类

| 症状 | 常见原因 | 改法 |
|---|---|---|
| 每一镜的主角长得不一样 | 纯文生视频没有身份锚点 | 改图生视频；先生成一张角色定妆图，之后每镜以它为首帧或参考图 |
| 脸崩 / 五官扭曲 | 脸太小、角度太偏、被遮挡 | 缩短景别（至少近景）、给正脸、避开低头与手挡脸 |
| 多手多指 / 手指粘连 | 手部精细动作是模型最弱项 | 让手出画、改拍手部局部特写、或让手只露一部分在画面边缘 |
| 人数忽多忽少 | 提示词没锁人数 | 写明「画面中只有一人」；多人场景拆成单人镜 |
| 服装 / 发型跨镜变色 | 缺一致性锚点 | 每条提示词**重复完整外观串**（发型+发色+上衣+下装），不要只写「她」 |
| 身材比例失真（腿过长 / 头过大） | 广角畸变 + 全身景别 | 改中景以上；广角镜让主体远离画面边缘 |

---

## 二、运动类

| 症状 | 常见原因 | 改法 |
|---|---|---|
| 动作抽搐 / 中间帧撕裂 | 单镜动作跨度太大，时长达标但内容超载 | 拆成两镜，一镜一个动作；时长压到 5 秒以内 |
| 画面整体闪烁、亮度跳变 | 模型对复杂光照不稳 | 换成单一光源 + 稳定时段；避开「烛光闪烁」「霓虹频闪」这类本来就抖的光 |
| 动作没做完就切 / 半途停住 | 时长不足以承载这个动作 | 延长时间，或把动作拆成「起手」和「完成」两镜 |
| 运镜没被执行 | 运镜混写（「先推再摇」），或运镜与动作冲突 | 一镜只写一个运镜；运镜写在动作之后，别和动作抢句首 |
| 慢动作失控（全片变慢 / 忽快忽慢） | 模型把「慢」理解成整段减速 | 不在句首写「慢动作」；局部变速交给后期，生成时只保证动作完整 |
| 主体僵住不动 | 提示词只有状态描述，没有动作动词 | 句首必须是**动作**（「她推开门走进来」），不是状态（「一个站在门口的女人」） |

---

## 三、画面类

| 症状 | 常见原因 | 改法 |
|---|---|---|
| 冒出文字 / 水印 / 乱码 | 写了「无字幕」这类否定句（negation summons），或提示词里带了数字与镜号 | 删掉所有针对文字的否定式；改用构图描述（「画面留白处无标识」）；提示词里不带镜号与时间 |
| 发灰发白、对比不足 | 缺光影描述，模型默认平光 | 补「光源方向 + 光比」（如「侧逆光 光比 1:4」）；避免只写「柔光」 |
| 过曝 / 高光死白 | 光源描述过强，或室内外交接处 | 降低光比，写明「阴影保留细节」 |
| 色彩与预期不符（发黄 / 发绿） | 只写了「电影感」这类空词 | 改成明确主色 + 胶片模拟（「青灰底 + 暖灯点，Kodak 250D」） |
| 构图乱飘、主体不在位 | 主体描述靠后，句首被风格词占了 | 主体动作提到句首；写明「主体位于画面中央 / 三分线交点」 |
| 多出无关元素 | 提示词里出现了具体名词（价格牌、海报、招牌、镜子） | 删掉这些名词；镜子反射尤其要避开 |
| 「AI 味」重（塑料感） | 缺材质描述 | 补材质词（「皮肤纹理真实」「磨砂表面」）；避免全片同一景别 |

---

## 四、物理类

| 症状 | 常见原因 | 改法 |
|---|---|---|
| 肢体互相穿插 / 穿模 | 多人同框接触动作 | 接触瞬间切走；复杂缠斗移出画面；或只拍单人反应 |
| 物件悬浮、没落在手上 | 模型对「握持 / 放置」这类接触关系理解弱 | 改成手部特写握持，或「物件放在桌面，手从旁边进入」 |
| 影子方向不对 / 没有影子 | 光源描述与场景不匹配 | 明确时段与方向（「午后侧光，影子朝画面右」） |
| 液体 / 烟雾形态诡异 | 流体是模型弱项 | 缩短流体出现时长；改用「水面静止」这类稳定状态；动态流体交后期 |
| 反射内容错误 | 镜面反射的逻辑模型跟不上 | 避开反射面，或让反射只占画面小角落 |

---

## 五、指令类

| 症状 | 常见原因 | 改法 |
|---|---|---|
| 提示词被完全忽略 | 太长、堆了太多并列从句 | 砍到 60 字以内，只留一条主线动作 |
| 只执行了前半句 | 句首权重高，后半句被稀释 | 最重要的信息放最前；一条提示词只做一件事 |
| 风格盖过主体 | 风格词放在了句首 | 主体动作永远句首，风格词放中后段 |
| 每次都生成同一个画面 | 提示词太笼统，没有区分特征 | 补具体特征：颜色、材质、动作方向、时段 |
| 改了一处，其它全变 | 正常现象——模型吃的是整体输入 | 局部修改用「首尾帧 + 局部重绘」，不要重写整条提示词 |

## 六、负面词库（可直接附加）

生成时固定附加这几类**实物**排除项：

```
多余肢体、多余手指、扭曲的脸、模糊五官、塑料感皮肤、
画面闪烁、抽帧卡顿、过曝、噪点、
水印、logo、乱码、
价格牌、促销贴纸、二维码、
镜面反射、镜像错误
```

英文版：

```
no extra limbs, no extra fingers, no deformed face, no blurry face, no plastic skin,
no flickering, no dropped frames, no overexposure, no noise,
no watermark, no logo, no gibberish text, no price tag, no promotional sticker, no QR code,
no mirror reflection, no mirrored artifacts
```

> ⚠️ 上面这组是「实物类」排除词，安全。但**不要写 `no text` / `no subtitles` / `无字幕`** 这类针对文字本身的否定式——它会把文字召唤出来。文字的处理方式永远是「用构图描述让画面干净 + 后期叠字幕」。

## 七、故事片专属崩坏

故事片的崩坏集中在**"情绪落不下去"**——镜头好看，但观众没有感觉。

| 症状 | 常见原因 | 改法 |
|---|---|---|
| 情绪落不到人身上 | 情绪只写在形容词里（「她很悲伤」） | 换成可拍的动作与状态：低头、肩沉、视线落地、环境压暗 |
| 人物表情假 / 像蜡像 | 让模型做复杂微表情（流泪、笑中带泪） | 特写少给、给就给正脸静态情绪；复杂表情交给「肢体 + 调度 + 光影」 |
| 台词对不上口型 | 台词过长、正脸不够干净 | 台词砍到一句 8 字以内；对口型必须有干净正脸，不给侧脸 |
| 场景跳变（同一场戏环境不一致） | 相邻镜的场景描述不一致 | 每条提示词重复完整场景串（时间 + 地点 + 天气 + 光源方向） |
| 光线情绪与剧情不符 | 只写「好看的光」 | 按情绪选光：孤独→侧逆光硬调；温暖→柔光平光；撕裂→硬光阴影 |
| 镜头之间不推进 | 缺少戏剧功能挂靠 | 回分镜检查每个镜头的「戏剧功能」列，答不出的删掉 |
| 一场戏拍得太完整、像流程记录 | 没做"晚进早出" | 从冲突进、在情绪到位时出；不拍进门→换鞋→坐下全流程 |
| 全片情绪一条平线 | 缺情绪曲线设计 | 分镜表后补「情绪曲线」一栏；没有起伏就加一处转折 |

### 故事片排错优先级

情绪落不到人身上 → 先处理（这是"漂亮但空洞"的判定线）
镜头不推进 → 回分镜重做，不要在提示词里救
光线情绪不符 → 改光线描述，成本最低、见效最快

## 排错流程（照着走）

```
生成一镜
  ↓
有崩坏？
  ├─ 否 → 锁定这一镜，记录它的提示词，后面的同类型镜头复用结构
  └─ 是 → 定位症状（查上面各表）
           ↓
        是人物 / 一致性崩？ → 换图生视频、补参考图（先改生成方式，别改词）
           ↓
        是动作 / 运镜崩？   → 拆镜、减动作、一镜一运镜
           ↓
        是画面 / 色彩崩？   → 补光影与色彩的具体参数
           ↓
        是物理 / 接触崩？   → 把接触移出画面，或只拍单人反应
           ↓
        都不是？            → 这一镜设计有问题，回分镜重做
           ↓
        重试 ≤ 3 次仍不行  → 换一个镜头方案，别死磕
```

---

## 记录习惯（避免重复踩坑）

每解决一个崩坏，在分镜表上加一列备注，写清「症状 + 改法」。攒够一屏就回填到本文件对应的表格里。

**踩过的坑不记录，等于每次重踩。** 这是本文件持续变厚的唯一方式。
