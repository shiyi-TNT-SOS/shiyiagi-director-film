# 情绪镜头设计层（故事片设计层）

> 本文件是 `shiyiagi-director-film` 的"设计层"——对应动作片 skill 的 `fight-design.md`、广告片 skill 的 `ad-structure.md`。
> 动作片在写镜头前先想"打什么"，广告片先想"靠什么被记住"，故事片在写分镜前要先想"这一镜的情绪靠什么画面兑现"。
> **"漂亮但空洞"的八成病因在这一步：镜头美，但情绪没落到镜头参数上，观众看完只记得"好像有点东西但说不清"。**

## 零、为什么需要这一层

故事片最典型的失败不是"不好看"，是"不推进 / 没魂"：

| 失败 | 表现 | 本层的治法 |
|---|---|---|
| 漂亮但空洞 | 镜头都美，但情绪不落人、不推进 | 先把**情绪值**逐镜标出来，再决定每个镜头怎么拍 |
| 情绪断片 | 上一镜暖、下一镜冷，观众出戏 | 情绪转场**至少改 3 个轴**，只改一个轴观众感觉不到 |
| 落点漂移 | 结尾停在高潮或硬切字幕 | 落点停在"释放后的平静"，**不在最高点硬切** |
| 母题丢失 | 开头埋的视觉符号结尾没回收 | 先定**视觉母题**，开头埋、结尾收 |

**核心判断**：故事片的质量八成在"开拍前把情绪落到参数上"。深度层（`narrative-structure.md`）管"人物怎么变"，本层管"人物的变靠什么画面让人看见"。跳过它，镜头再漂亮也只是素材。

## 一、情绪值 ↔ 镜头参数映射

`production.md` 六.6.2 要求把情绪曲线逐镜标值（1–5）。这里补上**参数映射**——情绪值不是形容词，是可直接填进 7 段 prompt 的取值：

| 情绪值 | ①构图景别 | ②运镜节奏 | ③光线 | ④色彩材质 | ⑤声音 |
|---|---|---|---|---|---|
| 1（最低 / 最孤） | 最大留白、人物极小且偏置或背对 | 固定长镜 ≥5s，不切 | 自然柔光，人物半明半暗 | 冷灰蓝，低饱和 | 空旷环境音，无配乐，静默多 |
| 3（中） | 中等景别，自然色 | 正常镜长，缓推/固定 | 常规光比 | 中性色，正常饱和 | 环境音 + 必要拟音 |
| 5（最高 / 最满） | 特写、人物占满画面 | 镜长最短、切点给反应 | 光比最大（硬光勾边） | 高饱和或强对比 | 声音最满**或最静**（见下） |

> **情绪高点用"最静"还是"最满"？看类型**：
> - **释放型**（哭、笑、和解、释然）→ 用"静"：周围声音突然抽走，只剩一声呼吸或环境音骤停。
> - **爆发型**（愤怒、决裂、崩溃）→ 用"满"：音效砸满、环境音压上。
> 用错会出现"情绪到了但没感觉"——这是最高频的"差点意思"。

## 二、情绪曲线设计（分镜前必画）

1. 先定这场戏的情绪起→承→转→落（只定一个主情绪走向，不要同时走两条线）。
2. 逐镜标**情绪值 1–5**（不是"悲伤/开心"这种词，是数值）。
3. **高点停留 ≥2 秒**：情绪最高点那一镜给足时长，不要在顶点刚到就切走。
4. **结尾停在"释放后的平静"**：落点镜头是情绪回落、人物状态归位，不是最高点。例：释然戏结尾是人物松肩、第一次环境音出现，而不是抱头痛哭的瞬间。

## 三、静默节点（情绪落点的放大器）

- 静默不是"没声音"，是**在情绪最高点前后故意抽走声音**，让一帧画面/一个表情成为全片最响的音。
- 用法：转折镜前给一拍静默（呼吸/停顿），落点镜用静默收（而非配乐涌起）。
- 判据：一场戏若全程有配乐，等于没有静默；静默必须**被设计出来**，不是"忘了配乐"。

## 四、环境承接情绪（环境是第五个角色）

- 环境不只为好看，要**反映/反衬人物状态**：孤独用空荡大空间 + 人物极小；压抑用门框/窗框/前景遮挡挤压主体。
- 环境变化 = 情绪变化的信号：释然时留白打开、光线回暖（与压抑段形成**色温差**）。
- 规则：环境只做"边"不做"体"——它是衬托人物的背景层，不抢戏、不解释。

## 五、视觉母题呼应（来自深度层）

深度层（`narrative-structure.md` 第 6 节）定了视觉母题（颜色/道具/重复动作/光线），本层负责**把它落到分镜参数**：

| 母题类型 | 开头（埋） | 结尾（收） | 参数呼应 |
|---|---|---|---|
| 颜色 / 光 | 一束冷光 | 同色光回暖 | 色温与亮度前后一致，形成闭环 |
| 道具 | 某物特写建立 | 同物同构图回收 | 同一机位/景别/光线复现 |
| 重复动作 | 低头回避 | 抬头直面 | 同一动作不同状态，镜头呼应 |

## 六、生成单元 ≠ 成片镜长（全系列统一口径）

| 项 | 取值 | 说明 |
|---|---|---|
| 生成单元 | **4–10 秒** | 一条 prompt 产出的片段长度，刻意留长给剪辑分段取用 |
| 成片情绪镜 | **1–2 秒** | 剪完每个镜头的最终长度，短视频节奏 |

> 生成单元 4–10 秒 ≠ 成片情绪镜 1–2 秒：前者是一条 prompt 出 5 秒情绪片段、剪辑只取其中 1.5 秒用，余量是给剪辑留的（取最稳的那一拍），不是浪费。与动作片 skill `fight-design.md` 第九节、广告片 skill `ad-structure.md` 第五节**同款口径**，全系列一致。

## 七、输出：情绪镜头设计表（分镜前必出）

| 项 | 内容 |
|---|---|
| 主情绪走向 | 这场戏从__情绪到__情绪（只一条线） |
| 情绪曲线 | 逐镜标值 1–5；高点位置与停留时长 |
| 静默节点 | 哪几镜抽走声音（转折前 / 落点） |
| 环境承接 | 环境怎么随情绪变（留白开合 / 色温冷暖） |
| 视觉母题 | 哪个元素贯穿、开头埋/结尾收的参数 |

**这张表在分镜表之前。** 它没填完，就不要写分镜——否则就是"一堆漂亮镜头拼在一起"。

## 自检（设计层交付前）

- [ ] 逐镜标了情绪值 1–5（不是形容词），高点停留 ≥2s
- [ ] 结尾停在"释放后的平静"，不在最高点硬切
- [ ] 情绪转场至少改 3 个轴（只改 1 轴观众无感）
- [ ] 静默节点被设计出来（非"忘了配乐"），释放型用"静"、爆发型用"满"
- [ ] 环境承接情绪（留白/色温随情绪变），环境只做"边"不做"体"
- [ ] 视觉母题开头埋、结尾收，参数前后呼应
- [ ] 情绪镜头设计表已出，在分镜表之前
- [ ] 生成单元 4–10s / 成片情绪镜 1–2s，余量给剪辑
