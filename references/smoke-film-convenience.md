# 行为冒烟示例（等级 2）· 雨夜便利店

> 本文件是 `shiyiagi-director-film` 的可执行测试：用一支 60s 短片「雨夜便利店」（孤独→温暖），跑通「情绪镜头设计 → 分镜表（含戏剧功能）→ 逐镜提示词」全流程，证明本 skill 能落地而非空话。

## 0. 测试场景

故事核心：加班女孩躲雨进便利店，与夜班店员无言的善意。情绪：孤独→温暖。画幅 2.39:1；生成单元 4–10s、成片情绪镜 1–2s。

## 1. 第 2 步（续）· 情绪镜头设计表

- 主情绪走向：孤独(1) → 戒备(2) → 松动(3) → 暖意(4) → 释然(5)
- 情绪曲线逐镜：1→2→3→4→5
- 静默节点：女孩接过热饮时 1 秒无声
- 视觉母题呼应：暖光玻璃门，开场冷蓝、结尾暖黄

## 2. 分镜表（5 镜，含戏剧功能列）

| 镜 | 画面 | 戏剧功能 | 情绪值 |
|---|---|---|---|
| 1 | 雨夜街，女孩抱肩跑入便利店 | 建置处境 | 1 |
| 2 | 店员推门，冷光玻璃映两人 | 制造张力 | 2 |
| 3 | 女孩拿泡面，手抖 | 转折前 | 3 |
| 4 | 店员默默递热饮，相视 | 释放 | 4 |
| 5 | 女孩出门，玻璃门暖黄映背影 | 释放后平静 | 5 |

## 3. 逐镜提示词（七段）

**镜 1（建置）**
> [女孩抱肩从雨中跑入，水珠甩落] + [全景·低角度] + [慢推] + [冷蓝街灯，店内白光溢出] + [冷青调] + [2.39:1·生成 6s] + [雨声，门铃]

**镜 4（释放）**
> [店员将热饮轻轻推过柜台，女孩抬眼] + [近景·平视] + [固定] + [暖黄台灯打两人脸，冷背景虚化] + [暖橙调] + [2.39:1·生成 5s] + [静默 1 秒 + 远处车声]

## 4. 自检（关键项）

- [x] 每镜挂靠戏剧功能（无挂靠=删）
- [x] 情绪靠镜头（光/色/调度），不靠旁白
- [x] 视觉母题（暖光门）首尾呼应
- [x] 情绪高点（镜4）未切，停留 ≥2s
- [x] 主体句首；生成单元 4–10s、成片 1–2s
- [x] 排除文字用构图

## 5. 结论

产出情绪设计表 + 5 镜分镜（含功能列）+ 2 条提示词，自检通过。反向对照：若跳过情绪设计，会产出"漂亮但空洞"的雨夜空镜。
